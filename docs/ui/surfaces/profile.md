# Profile and Settings

**Responsibility:** review personal progression and manage account preferences.

**Primary action:** contextual `保存设置` only when timezone or daily budget is dirty.

**Required content:** level, earned badges, timezone, daily time budget, password change and active-session management. Explain that timezone changes affect future streak dates and are rate-limited.

**Exclude:** course browsing, live study, other users’ details and administrator account management.
