# Challenge Quiz

**Responsibility:** let a learner complete one focused, server-authoritative 10-question weekly challenge attempt.

**Primary action:** submit the current answer. After feedback, “下一题” becomes the sole primary action. Exiting before completion asks for confirmation because accepted answers and points remain final.

**Required content:**

- minimal header only: exit, `n / 10`, programmatic five-minute countdown, and no global learner navigation;
- source course, question direction and prompt; exactly five English→Chinese four-choice questions and five Chinese→English spelling inputs per attempt;
- a quiet “本题答对可得 5 分” or “复习题，不重复得分” status before submission, plus the attempt's maximum potential score at start;
- immediate inline correct/incorrect feedback, correct answer, awarded `0` or `5` points and retry-safe pending state; no speed bonus;
- explicit states for offline/retry, expired timer, server conflict, start cutoff, and recovery of an existing active attempt.

**Rules expressed by the UI:** input accepts case/outer-space-insensitive spelling only; internal spaces and hyphens are meaningful. The same word never appears twice in one attempt, including the opposite direction. Do not show an answer before that question is submitted.

**Exclude:** FSRS ratings, daily-plan controls, leaderboard rows, chat, hints generated by AI, camera/proctoring UI, score editing and decorative animation.
