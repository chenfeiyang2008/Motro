# Challenge Quiz Result

**Responsibility:** close one completed or expired quiz attempt and explain its objective result.

**Primary action:** “返回周挑战榜”. A neutral “再测一次” is available only when the week is open and no active attempt exists; it must not compete visually with return.

**Required content:** correct answers out of 10, new challenge points in this attempt, count of already-scored review questions, current personal weekly points/rank summary and any applied adjustment explanation. State that speed did not change score and that daily XP is separate.

**Exclude:** confetti, exaggerated celebration, timers, answer changes, a full leaderboard table, daily-study result metrics and extra primary actions.
