# Admin Publishing

**Responsibility:** validate a course draft and create or select an immutable release.

**Primary action:** `发布版本` after all blocking checks pass.

**Required content:** draft-to-current diff summary, blocking errors, warnings, affected learner count, release note, version history and current-version pointer. A confirmation dialog states immutability and exact version number.

**Exclude:** editing draft content, opaque one-click rollback and job logs unrelated to this release.
