# Admin Course Composition

**Responsibility:** edit one course draft’s units and ordered course items.

**Primary action:** `保存草稿`; publishing is a separate surface.

**Required content:** course metadata, unit outline, stable item identity, add/search word item, ordering controls, course-specific Chinese meaning, unsaved-state indication and validation summary. Drag-and-drop has accessible move alternatives.

**Exclude:** learner answering, release execution, global lexical-entry editing beyond linked context and import job monitoring.
