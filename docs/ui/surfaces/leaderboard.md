# Weekly Leaderboard

**Responsibility:** show the current all-user weekly ranking.

**Primary action:** none; this is a read-only comparison surface.

**Required content:** week range and cutoff in the viewer’s timezone, rank, display name, XP, current-user highlight and tie explanation. Provide a respectful empty/offline state.

**Exclude:** lifetime analytics, direct messaging, follow/friend controls, public profiles, betting-like movement and urgency prompts.
