# Admin Lexicon

**Responsibility:** search and maintain reusable lexical entries and their provenance.

**Primary action:** `新建词条`; row editing opens a dedicated page or drawer.

**Required content:** spelling, senses/parts of speech, source status, use count, last review, filters, duplicate warning and provenance detail. Course-specific meanings are shown only as references, edited in course context.

**Exclude:** import mapping, course ordering, publishing and a dashboard of unrelated counts.
