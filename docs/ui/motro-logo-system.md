# Motro 标志系统

这是 Motro「01｜开放端点 · 轨道 M」的 Web 使用规范。标志表达两条持续向前、彼此交会的学习轨道；它是品牌识别，不是状态图标，也不是装饰性插画。

## 标志资产

生产代码中的唯一来源是 [`MotroLogo`](../../apps/web/src/components/motro-logo.tsx)。组件通过 `currentColor` 继承语义颜色，不在 SVG 内写死品牌色。

| 变体 | 用途 | 规则 |
| --- | --- | --- |
| `full` | 登录页、品牌板、较宽的品牌锁定 | 保留两条交会轨道和四个开放端点；建议 32px 以上 |
| `compact` | 学习端/管理端侧栏、Dock、favicon、应用图标 | 保留同一开放端点结构，只增加笔画重量；16px 是最低使用尺寸 |
| 单色反白 | 深色背景、打印和降级模式 | 只改变 `currentColor`，不改变结构或加阴影 |

### 最小尺寸与留白

- `compact` 在 Web 控件中不小于 16 × 16px；低于 20px 时使用 compact，不使用 full。
- 标志绘制比例约为 1.5:1（宽:高）；容器可以是方形，但不得把 SVG 拉伸成正方形。
- 标志周围保留至少一个标志笔画宽度的安全空间；品牌锁定旁的 Motro 字标与标志间距为 12–16px。
- 不拉伸、不压扁、不旋转、不裁切，不把标志放进第二层装饰圆环或渐变贴纸。

## 颜色

默认使用语义色：浅色主题为深墨 `--color-text-primary`，深色主题为暖白 `--color-text-primary`。品牌橘橙 `--color-brand-600` 只在需要明确品牌识别的主标或主操作附近使用；不要把 Logo 变成所有导航项的橙色图标。

浅色方向采用「A｜象牙工作室」：暖象牙背景、深墨文字、小面积橘橙强调。深色方向使用深暖墨背景与暖白标志。单色版必须在不透明浅/深表面上保持清晰对比；不能依赖玻璃高光、折射、阴影或颜色渐变来辨认标志。

## 组合与无障碍

- 标志旁已有可见 “Motro” 字标时，SVG 使用 `aria-hidden="true"`；只有图标的链接或按钮必须提供 `aria-label="Motro 首页"` 等可访问名称。
- 登录页使用标志 + 字标组合；学习端和管理端侧栏使用 compact 标志，避免在窄屏占用内容空间。
- 浏览器 favicon 使用同一几何的深暖墨底反白资产 [`app/icon.svg`](../../apps/web/src/app/icon.svg)；不能另画一个简化到变形的 M。
- 标志不承载用户头像、等级、XP、课程状态或 provider 状态；这些事实必须由对应文字和语义图标表达。

## 禁止事项

- 不添加渐变、霓虹、持续扫光、彩色折射、浮雕或玻璃高光。
- 不把标志当作 loading 动画、成功庆祝或可点击但没有名称的装饰。
- 不从截图重新描摹或创建第二份 SVG；任何新尺寸先复用 `MotroLogo`，再由设计审查决定是否需要真正的新变体。
