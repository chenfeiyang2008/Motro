# Motro 高级配色实验室（Throwaway）

问题：品牌橘如何在不显廉价、不牺牲可读性和状态语义的前提下，形成更有层次的高级感？

这是独立的只读 UI 样板，不连接后端、数据库或正式页面。它提供三个结构与中性层不同的方向：

- `?variant=A`：象牙工作室。温暖、编辑感、最接近 Motro 的长期品牌气质。
- `?variant=B`：矿物学习室。微青灰的中性层，理性安静，数据层次更强。
- `?variant=C`：石墨画廊。建筑感与高对比更明显，视觉记忆最强，也最需克制使用。

每套方案都有独立的夜间材质与中性色，不是把浅色版简单反相：

- `?variant=A&theme=dark`
- `?variant=B&theme=dark`
- `?variant=C&theme=dark`

在仓库根目录运行：

```sh
python3 -m http.server 4174 --directory prototype/brand-color
```

打开 [http://localhost:4174/?variant=A](http://localhost:4174/?variant=A)。底部原型切换条或键盘左右方向键可切换 A/B/C；点击“夜/日”可切换深浅主题，两个状态均由 URL 保持。点击“开始学习”可查看行动后的颜色反馈；刷新时只会重置该临时反馈，不会重置配色方向或主题。

对比时不只看“喜不喜欢”，还要看：品牌橘是否仍是唯一强调；夜间文字和按钮是否仍有足够对比；学习数据是否比卡片效果更先被看到；390px 下主操作是否清楚；Glass 回退为实色后是否仍成立。

该目录是一次性决策材料，不得直接作为生产实现。
