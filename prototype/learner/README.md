# Motro 学习者交互原型（Throwaway）

最终设计决定：选择「计划优先」。它让学习者先理解今天投入的时间与任务，再进入单卡学习；该结论已同步到 `DESIGN.md`、`docs/ui/web-ui-spec.md`、`docs/ui/surfaces/home.md` 和 `docs/ui/surfaces/study.md`。

这是一个无后端、无数据库、无真实 FSRS 的临时 UI 原型。状态仅保存在浏览器内存中，刷新即重置。

在仓库根目录执行：

```sh
python3 -m http.server 4173 --directory prototype/learner
```

打开 [http://localhost:4173/](http://localhost:4173/)。

- 计划面板是视觉中心，课程、连续天数和带星期信息的本周学习节奏作为旁侧事实。
- 顶栏/侧栏中的头像与“尊享会员”身份为静态占位，后续替换为真实头像与账户会员类型。
- Liquid Glass 只用于功能性导航层：移动端胶囊 Dock、桌面左贴边侧栏与紧凑顶栏；计划与学习卡维持实体内容面，并在减少透明度、高对比度或不支持背景模糊时回退为不透明表面。Dock/侧栏通过半透明基底、局部内外边缘和有偏移的软阴影形成厚度，不用扫光、渐变边框或动态模糊伪造效果。
- 学习时隐藏全局导航；紧凑头部显示退出和进度，卡片状态切换后焦点落到下一项可操作控件。

交互：点击“开始学习”进入新词学习面；继续到英文→中文、中文→英文卡片；“显示答案”后可用 Again / Hard / Good / Easy 或键盘 `1`–`4` 评分。评分会推进到下一张卡并最终显示完成状态。

响应式验收范围：

- **390px**：单列计划与事实、移动顶栏、底部安全区内的 4 项胶囊 Dock；Dock 不遮挡“开始学习”。
- **768px**：保留触控友好的 Dock；计划保持完整宽度，课程/连续学习事实并列，本周学习节奏独占一行。
- **1440px**：导航切换为左贴边的连续 Glass 侧栏；计划与辅助事实并列，学习会话仍隐藏全局导航。

该目录不应作为生产实现的一部分保留；选定方向后应在正式应用中重新实现。
